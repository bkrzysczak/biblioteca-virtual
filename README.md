# Biblioteca Virtual
Um simples gerenciador de livros com banco de dados
---
A Biblioteca Virtual é um software pensado para simples gerenciamento de livros. Possui interface em linha de comando (CLI) e conta com seu próprio banco de dados SQLite para armazenar o catálogo.
## Funcionalidades
* Cadastrar e remover livros (ID único, nome, autor, ISBN e quantidade)
* Empréstimo e devolução
* Listagem completa do catálogo
* Consultas por nome ou autor
